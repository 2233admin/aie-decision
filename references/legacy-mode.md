# Explicit legacy/manual mode

Read this reference only when the user explicitly asks for `legacy`, `manual`, or the former conversational workflow.

State before proceeding that legacy mode is a heuristic conversation and does not run the standalone compiler, validate schemas, create an immutable ledger, or produce an accepted analysis package.

Use the old workflow only as lightweight questioning:

1. Clarify the decision, target, horizon, unit, and decision threshold.
2. Separate supplied facts from attributed claims, assumptions, and unknowns.
3. Decompose the question into necessary conditions.
4. Ask for bounds and their derivation instead of inventing point estimates.
5. Identify the next information that could narrow a bound or resolve a decision.

Do not claim Bayesian updating, empirical calibration, evidence acquisition, portfolio sizing, stop-loss optimization, or external-system execution unless a separate verified implementation actually performed that work. Do not relabel the conversation as a standalone compiler result.

Offer to convert the supplied material into formal compiler input when the user wants durable artifacts.
