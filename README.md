# AIE Decision

AIE Decision 正在建设一个供 AI 使用的费米分解运行时。它的核心任务不是让用户填写公式，也不是从固定领域模板中挑选答案，而是帮助 AI 把一个看似不可估计的问题递归拆成可观察、可计数、可测量的原子量，并用目标不确定性判断何时停止拆解。

当前仓库中的运营吞吐量估算器是一次方向错误的受控原型，不代表产品第一版，也不作为端到端验收路径。它只可被视为待替换的确定性算术实验代码。

产品方向与第一版边界见 [费米分解产品方向](docs/FERMI-PRODUCT-DIRECTION.md)。新的实现规格将在该方向确认后通过 OpenSpec 建立。

## 当前状态

- 产品方向：已纠偏，等待正式 OpenSpec。
- 当前实现：尚未达到第一版产品要求。
- `fermi.py`：至多作为区间算术基础设施保留。
- 固定吞吐量语法、固定候选公式和 prompt 包装：不属于目标产品。
