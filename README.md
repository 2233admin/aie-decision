# AIE Decision Framework for Quant Trading

> 基于《如何衡量万事万物》(How to Measure Anything) 的决策分析框架
> 专为量化交易场景设计

## 🎯 这是什么

AIE (Applied Information Economics) 是一个将**模糊问题转化为可执行决策**的框架。

特别适合量化交易场景：
- 因子开发决策
- 策略参数选择
- 仓位管理判断
- 风险管理评估

## 📚 核心方法

### 1. 费米分解 (Fermi Decomposition)

把"我不知道"拆解成"我知道的小问题"：

```
❌ "这个因子有没有用？"

✅ "根据：
   - 历史IC均值约5%
   - 波动率约3%
   - 最大回撤约8%
   → 估计有效概率60-80%"
```

### 2. 校准评估 (Calibrated Estimation)

给出90%置信区间：

```
"我有90%把握，这个因子IC在3%-8%之间"
```

### 3. 贝叶斯更新 (Bayesian Update)

先验 + 新证据 = 后验：

```
先验：根据经验，胜率约50%
新证据：10次测试7次盈利
后验：胜率更新为55-70%
```

## 🔄 使用流程

```
1️⃣ 厘清决策问题
   └── 这个决策是什么？后果是什么？

2️⃣ 费米分解
   └── 你知道什么相关的事实？

3️⃣ 90%置信区间
   └── 你的估计范围？

4️⃣ 决策分支
   └── 超过阈值怎么做？低于阈值怎么做？

5️⃣ 执行与复盘
   └── 追踪结果，修正估计
```

## 📊 量化交易示例

### 示例1：因子开发决策

```
问题：要不要把这个现象做成因子？

费米分解：
- 现象：换手率变化与收益有相关性
- 证据：研报中提到过类似研究
- 先验：类似因子IC约3-6%

90%置信区间：
- 下限：1%
- 上限：8%
- 中点：4%

决策：
- 如果IC > 3% → 加入候选
- 如果IC < 1% → 放弃
```

### 示例2：策略选择

```
问题：策略A vs 策略B，选哪个？

费米分解：
- 策略A：历史年化15%，最大回撤20%
- 策略B：历史年化12%，最大回撤12%

90%置信区间（未来1年）：
- 策略A收益：5%-25%
- 策略B收益：3%-20%

决策：
- 如果追求高收益 → 选A
- 如果控制回撤 → 选B
```
